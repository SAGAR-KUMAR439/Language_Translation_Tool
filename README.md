# CodeAlpha Language Translation Tool

## ?? Project Overview

This project is a Language Translation Tool developed as part of the CodeAlpha Artificial Intelligence Internship.

The application allows users to enter text, select a source language and a target language, and translate the entered text into the selected language.

## ? Features

- Simple and user-friendly graphical user interface
- Text input and translated text output
- Source and target language selection
- Translation using a translation service
- Error handling for empty input and translation errors
- Clear button to reset the input and output

## ??? Technologies Used

- Python
- Tkinter
- Googletrans
- Asyncio
